# Privacy Policy and User Guide

## 1. Purpose of the Project

Maze Runner is an educational single-page web application created as part of a university software development assignment. The application allows the user to start a maze game, configure gameplay settings, complete levels, and review saved results.

## 2. How to Use the Application

1. Open the start page.
2. Move to the game menu.
3. Choose the game mode, difficulty, and timer settings.
4. Start the game and complete maze levels.
5. Review your results on the results page.

The application is intended for demonstration, learning, and local interactive use.

## 3. Data Processed by the Application

The current version of Maze Runner does not require user registration and does not process direct personal identifiers such as:

- full name
- email address
- phone number
- payment information
- passport or government identification data

The application may store only technical and gameplay-related information in the user's browser:

- selected game mode
- selected difficulty
- selected timer mode
- selected time limit
- saved game statistics and level results
- cookie consent preferences

## 4. Storage Method

At the moment, the project is designed as a local client-side application. The main data storage mechanism is browser-side local storage such as `localStorage`. No dedicated remote backend or user account system is used in the current version of the project.

If the project is later deployed with external services, analytics, or cloud storage, this policy must be updated before public use.

## 5. Cookies and Similar Technologies

Maze Runner may use cookies or cookie-like browser storage only for functional and consent-related purposes, including:

- saving the user's consent choice
- remembering local configuration values
- preserving a better user experience between sessions

The project does not currently declare advertising cookies or behavioral tracking cookies. If analytics or marketing tools are added in the future, the consent banner and this document must be updated accordingly.

## 6. GDPR-Oriented Notice

Because the project may be demonstrated or published online, the following privacy principles apply:

- data minimization: only the minimum technical data required for local gameplay should be stored
- purpose limitation: stored data is used only for gameplay configuration and user experience
- transparency: the user should be informed what is stored and why
- control: the user should be able to accept, reject, or later change non-essential consent choices

If this project is made publicly accessible in the European Union or targets EU users, the maintainer should ensure the final deployed version includes:

- a visible cookie consent mechanism
- access to this privacy document
- the ability to withdraw optional consent
- an updated contact and controller section when real personal data processing exists

## 7. User Rights

For the current local-only version, most information is stored only in the user's own browser. A user may control or remove this data by:

- clearing site storage in the browser
- removing cookies related to the project
- resetting browser data for the site

If a hosted version is introduced later and personal data is processed by a project owner, users should also be granted rights consistent with applicable law, including access, correction, deletion, and restriction where relevant.

## 8. Limitations of Use

The project must not be considered:

- a commercial game service
- a production-grade analytics platform
- a system for storing sensitive or confidential information

Users should not enter personal or sensitive data into the application because it is not designed for such processing.
