# ⚔️ Maze Runner — React Neon Dungeon Game

Maze Runner — це міні-гра на React, де користувач керує мандрівником у неоновому лабіринті 
та намагається знайти портал. Гра включає різні режими складності, таймер, систему рівнів 
та збереження результатів.

---

# 🎮 Особливості гри

- 🌐 **Dynamic Routing**: `/user/:id/start`, `/menu`, `/game`, `/result`
- 🧠 **Повноцінний Redux Toolkit стейт менеджмент**
- 🕹 **Два режими гри**: Adventure & Custom
- ⏳ **Таймер-режим**: без ліміту або з обмеженням часу
- 🔐 **Детерміноване генерування лабіринтів**
- 💡 **Неонова dungeon-стилістика**
- 📱 **Повністю адаптивний інтерфейс**

---

# 🚀 Використані технології

- **React (CRA)**
- **Redux Toolkit**
- **React Router v6**
- **CSS Modules**
- **Formik + Yup (налаштування гри)**
- **React Portals (модалки)**

---

# 🧠 State Management (Redux Toolkit)

### Стейт поділено на два модулі:

### `gameSettingsSlice`
- режим гри (adventure / custom)
- складність
- режим таймера
- ліміт часу

### `gameStateSlice`
- рівень
- складність рівня
- записані результати
- логіка переходу між рівнями

> Обидва slices імпортуються у `store/store.js`.
